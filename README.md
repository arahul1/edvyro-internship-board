
# InternshipHub — Responsive Internship Board

A responsive internship listing interface built with semantic HTML, CSS, and vanilla JavaScript.

## Live Demo

- **Website:** Add your deployed website URL
- **GitHub Repository:** Add your repository URL

## Objective

Practice semantic HTML, responsive CSS, DOM rendering, filtering, and accessible interactions.

## Features

- Responsive mobile, tablet, and desktop layouts
- Search by role, company, domain, location, and description
- Domain-based filtering
- Dynamic internship card rendering
- Combined search and domain filters
- Empty-results and rendering-error states
- Accessible labels, keyboard navigation, and visible focus indicators
- Clear filters and retry controls
- Reusable internship data

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub
- Netlify for deployment

## Run Locally

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder.
3. Open `index.html` in a browser.
4. Test keyword search, domain filters, and the clear-filters button.

No framework or package installation is required.

## Accessibility

The project uses semantic HTML, labelled form controls, keyboard-operable native inputs and links, visible focus indicators, and live status messages.

## Learning Outcomes

- Creating semantic web page structures
- Designing responsive layouts using CSS Grid and media queries
- Rendering data dynamically using the DOM
- Combining search and filtering conditions
- Handling empty results and rendering errors
- Documenting and deploying a web project
